# narrativesBERT
Using Topic Modeling to Study the Narratives of Earnings Calls

## Pre-run
- **Python version**: 3.8.19

1. **Enter the node** (for example, `c1701`):
   ```bash
   srun --partition=gpu72 --pty bash
   ```
2. **Submit the job**:
   ```bash
   sbatch submit_job.sh
   ```

## What Does the Code Do (in Detail)?
1. **Class Definition**: 
   - The `BERTopicGPU` class is defined, which encapsulates all the methods and properties needed for topic modeling using the BERTopic algorithm on a GPU.

2. **Constructor Initialization**: 
   - **CUDA Memory Management**: Clears the GPU cache and optimizes CUDA settings for better performance.
   - **Embedding Model**: Initializes a `SentenceTransformer` model for generating embeddings from text.
   - **UMAP Model**: Configures UMAP for dimensionality reduction, optimizing for GPU memory usage.
   - **HDBSCAN Model**: Sets up HDBSCAN for clustering, with parameters for memory management and performance.
   - **Vectorizer**: Initializes a `TfidfVectorizer` for transforming text data into a format suitable for modeling.
   - **Representation Model**: Sets up different representation models for topic representation.

3. **Loading Data (`load_data` method)**: 
   - This method checks if a specified CSV file exists. If it does, it reads the data in chunks, filters it based on certain criteria (like year), and concatenates the filtered chunks into a single DataFrame.

4. **Text Preprocessing (`pre_process_text` method)**: 
   - This method preprocesses the text data by removing unwanted entries, converting text to a string format, and applying NLP preprocessing. It also extracts relevant features like post date and year.

5. **Filtering Empty Topics (`filter_empty_topics` method)**: 
   - This method filters out topics that do not contain any valid words, ensuring that only meaningful topics are retained.

6. **Computing Coherence Score (`compute_coherence_score` method)**: 
   - This method calculates the coherence score of the topics generated by the model. Coherence scores help evaluate the quality of topics by measuring the degree of semantic similarity between high-scoring words in a topic.

7. **Batch Processing for GPU (`process_batch_gpu` method)**: 
   - This method processes documents in batches to generate embeddings using the embedding model. It handles smaller sub-batches to optimize memory usage and performance.

8. **GPU Memory Monitoring (`print_gpu_memory` method)**: 
   - This method prints the current GPU memory usage, helping to monitor resource allocation during processing.

9. **Running BERTopic (`Bertopic_run` method)**: 
   - This method orchestrates the main workflow of the BERTopic model:
     - It calculates the optimal batch size based on available GPU memory.
     - It processes documents in batches to generate embeddings.
     - It fits the BERTopic model using the generated embeddings and saves the model.

10. **Saving Results (`save_file` and `save_figures` methods)**: 
    - These methods save the processed documents and visualizations of the topics to specified file paths.

11. **Dimensionality Reduction (`reduce_dimensionality` method)**: 
    - This method reduces the dimensionality of the embeddings using PCA, which can help in visualizing and interpreting the data.

12. **Loading Documents in Chunks (`load_doc_chunk` and `load_doc_parallel` methods)**: 
    - These methods load documents from a text file in chunks, allowing for efficient reading and processing, especially for large files.

13. **Optimizing Model Parameters (`optimize_model_parameters` method)**: 
    - This method performs a grid search to find the best parameters for the BERTopic model based on coherence scores. It tests different combinations of parameters and keeps track of the best-performing set.

14. **Main Execution Block**: 
    - The `if __name__ == "__main__":` block initializes the `BERTopicGPU` class, checks for preprocessed documents, and either loads them or processes raw data. It then runs the BERTopic model and saves the results.
